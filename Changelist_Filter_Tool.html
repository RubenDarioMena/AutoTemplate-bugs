Jira Changelist Filter Tool

CSV → filtro por changelist/build → Key in (...)

1. Archivo CSV

Detecta automáticamente coma o punto y coma y respeta campos entre comillas.

Ningún CSV cargado Se validarán los headers configurados en la pestaña HEADERS.

2. Build general

Se usa salvo que el Summary coincida con una regla Map / Release.

Regla base: incluir si changelist ≤ build o si changelist está vacío. Una coincidencia Map / Release sustituye build por su buildMap antes de evaluar la fila.

3. Overrides por Map / Release

La primera regla que coincida con Summary define el buildMap efectivo de esa fila.

Map Name y Release Name buscan coincidencia parcial sin distinguir mayúsculas. _, - y espacios se consideran equivalentes.
